# Ethicore Privacy Policy

Effective date: 2026-09-09

Ethicore is an educational application for Social and Professional Issues learning activities.

## Information sent for evaluation

When a user requests an AI evaluation, Ethicore sends the selected decision, the related scenario, and the relevant course context to the Ethicore evaluation service hosted on Vercel. That service sends the request to the configured AI processing provider to produce the response shown in the application.

EthiCore does not place AI provider API keys in the mobile application. API credentials are stored as server-side Vercel secrets.

## Local information

Course progress, activity state, user notes, and scenario history may be stored on the device so the application can preserve learning activity. Ethicore does not use advertising identifiers, location, contacts, camera, microphone, or background tracking.

## Service providers

Vercel hosts the evaluation endpoint. The configured AI processing provider processes evaluation requests. Their handling of data is subject to their own privacy policies and terms.

## Retention and deletion

Evaluation request retention depends on the configured service providers and their applicable policies. Do not submit sensitive personal information in a decision or scenario. To request information about data associated with an evaluation request, contact the app publisher:
